# 生物实验：业务流程与架构

## 1. 定位与范围

“生物实验”（`biology-lab`）用于高中课堂的离线实验演示。首版实现“探究生长素类调节剂促进插条生根的最适浓度”，优先对齐视频中的界面布局、操作步骤、过程变化和结果分析。植物等位图重新生图制作，因此不承诺与原软件素材逐像素相同。

已分析三段用户提供的视频：插条生根（08:45）、洋葱表皮细胞质壁分离与复原（07:05）、土壤微生物分解淀粉（07:55）。三个视频呈现相同风格和操作框架；这是界面观察，不能据此确定原软件内部架构。

## 2. 程序主流程

```text
选择实验
  → 实验原理 → 实验目的 → 材料用具
  → 开始实验
  → 阶段选择 → 步骤选择 → 操作器材 → 计时/观察 → 结果分析
  → 讨论要点
  → 返回资料页 / 返回实验目录 / 重新开始
```

- 实验目录是按本项目需求新增的入口，三段参考视频均未展示原软件目录。
- 上述“原理→目的→材料”是推荐教学顺序；视频中的资料是可直接切换的页签，不能强制用户依次读完。
- 资料页包括“实验原理、实验目的、材料用具、讨论要点”。视频在原理和目的页同样显示“开始实验”，实现保留这一行为。
- 实验场景顶部显示实验名、返回、关闭；底部左侧是该实验的阶段，左下浮动面板是当前阶段的步骤，右下是讨论和重新开始。
- 点击物体完成相应器材操作，物体移动、液体变化或显微观察给出可见反馈；当前步骤高亮，完成后出现完成状态。
- 时间类操作使用压缩计时与可拖动滑块，滑块末端代表实验时长结束，不要求真实等待数小时或数天。
- 结果按实验性质呈现：生根曲线和数据表、显微细胞图像、试剂颜色对照，不能强制所有实验都有统计图。
- 讨论题可独立展开/收起，关闭讨论后保留场景状态。

## 3. 三个参考实验的共性与差异

| 维度 | 插条生根 | 质壁分离与复原 | 土壤微生物分解淀粉 |
|---|---|---|---|
| 阶段 | 预实验、正式实验 | 制作装片并观察、滴加蔗糖溶液、滴加清水 | 制土壤浸出液、设置对照实验、鉴定 |
| 步骤数 | 每阶段 3 步 | 4、2、2 步 | 3、2、3 步 |
| 核心交互 | 逐组移入烧杯、移至滤纸、计时 | 制片、滴液、吸引、显微镜观察 | 加液、混合、恒温培养、试剂鉴定、水浴 |
| 结果 | 平均生根数曲线与逐日数据表 | 细胞图像及状态变化 | 试管颜色变化 |
| 公共能力 | 资料页、阶段/步骤、反馈、讨论、重置 | 同左，增加显微观察视图 | 同左，另有“相关实验”入口 |

“显微镜”和“相关实验”作为将来具体实验的扩展能力，首版不实现空入口。阶段个数、步骤个数、结果类型都由具体实验定义。

## 4. 技术方案

- **Vue 3 + TypeScript + Vite**：负责资料页面、实验交互和状态，使用 Composition API；公共组件传入内容、通过事件返回用户意图。
- **Tauri 2**：Windows 桌面外壳、窗口和打包。首版没有业务服务器，Rust 只保留必要桌面能力。
- **DOM/CSS + SVG**：器材图层、转移动画、按原始数绘制根、曲线、坐标轴、数据表。当前只有小型统计曲线，无需额外图表引擎或 3D 引擎。
- **模块登记 + 独立运行组件**：`ExperimentDefinition` 提供 ID、标题、资料、阶段概述和可运行状态；目录按登记渲染。公共层通过模块 ID 选择运行组件，未知或未开放 ID 不进入实验。
- 生根运行状态集中于独立 composable；阶段分别保存步骤、物体位置、计时进度和完成状态。原始数据是唯一数据源，平均值统一计算到一位小数。
- npm 与 `package-lock.json`；依赖锁定提交到项目，GitHub Actions 通过 `npm ci` 安装。按需使用 Vitest 测试领域数据和状态，不为静态介绍页面堆积测试。
- 不引入账号、数据库、联网资源、在线生图、热加载插件或后台管理；保持离线包结构简单。

## 5. 显示、状态及边界

- 采用深灰背景、绿色选中状态、白色文字，按参考视频保持标题、步骤面板、阶段按钮和器材的位置关系。
- 实验舞台按固定设计比例等比缩放，适配 1366×768、1920×1080 及 Windows 显示缩放；减少动画设置下缩短移动动画。
- 同组枝条重复点击不叠加，正在移动时锁定该操作；全部组移入后才开始该步骤的计时。
- 计时结束后可进入下一步；未达到前置条件时提示原因。重新开始重置本实验两阶段；返回资料页保留当前会话进度，返回目录后重新进入建立新会话。
- 步骤间回看保留已完成结果，不通过回看伪造未做的步骤；切换阶段分别保存状态。
- 实验中打开讨论暂停计时，关闭后由用户继续；切换阶段或离开场景取消正在执行的定时器，避免旧任务写入新状态。
- 首页中另两个实验只显示“待扩展”，不宣称可运行。

## 6. 素材与离线分发

- 生成月季枝条、玻璃烧杯、滤纸素材，透明背景并保存到项目 `public/assets/`，各场景复用同一组素材。
- 图片不含中文标签、坐标轴或结果表；这些内容用代码呈现，保证准确。
- GitHub Actions 准备 Windows x64 构建，产物含桌面程序及 NSIS 安装包。首版安装包带 WebView2 离线安装器，覆盖目标电脑未安装运行时的情况。
- GitHub 工作流配置不等于已打包成功。实际上传仓库、运行工作流、签名和发布必须单独记录，不隐含已获授权。
- 官方依据：[Tauri GitHub 构建](https://v2.tauri.app/distribute/pipelines/github/)、[Windows 安装与 WebView2](https://v2.tauri.app/distribute/windows-installer/)。

## 7. 验收

1. 从目录进入生根实验，四个资料页签可切换，“开始实验”可进入场景。
2. 两阶段各三步，逐组点击、移动、计时、前置校验、阶段保存和重新开始均可用。
3. 第四天曲线与表格显示《实验手册》中的全部原始数据；两种视图可切换，根的数量取对应组的三条记录。
4. 预实验定位较适宜浓度范围，正式实验中 5 ppm 组最高；不把该结果泛化为全部植物的普适最适浓度。
5. 讨论打开/关闭及题目展开/收起正常；不混淆视频已展示答案与补充答案。
6. 类型检查、生产构建、核心测试通过；离线资源无外链，窗口与安装包的验证状态如实记录。

- 用内置 imagegen 基于原烧杯生成半杯无色透明溶液素材，保留杯体轮廓、视角及透明背景；通过自然椭圆液面、弯月面和柔和折射表现液体，移除矩形 CSS 液体色块。

- 移动完成事件控制首次湿痕出现；回看步骤直接恢复当前状态，切换阶段及重置不继承旧视觉状态，减少动画模式立即反映接触。
- 此次只修改视觉表现与视觉状态传递，不更改步骤、浓度、原始统计数据或计时规则。
